# Value Proposition

## User Value
- Less manual investigation.
- More context-aware recovery decisions.
- Clear explanation of why an action was chosen.
- Reduced unnecessary customer friction.

## Merchant Value
- Higher expected recovery efficiency.
- Incremental revenue visibility.
- Bounded automation.
- Audit trail and merchant approval controls.

## Razorpay Value
RecoverAI can demonstrate an intelligent layer that makes stronger use of payment context and Razorpay execution capabilities while complementing existing recovery products rather than replacing them.

## Revenue Impact
Primary value is incremental recovered revenue relative to baseline.

## Operational Impact
The system can reduce manual case-by-case decision effort by automating investigation and bounded execution for eligible cases.

## Why Adaptive Agent
Recovery outcomes are uncertain. The system needs to combine context, candidate actions, predictions, constraints, execution, and feedback rather than merely fire a fixed rule.
