# Differentiation

## Not a Retry Engine
Retry is one candidate intervention. RecoverAI evaluates retry alongside other eligible actions.

## Not a Chatbot
Conversation is not the product. The product is a revenue recovery decision workflow.

## Not a Dashboard
Analytics support the product but do not constitute its core value.

## Not a Rules Engine
Rules enforce eligibility and guardrails. They do not alone provide contextual probabilistic decisioning.

## Not a Generic AI Agent
The agent has a narrow objective, bounded tools, structured state, measurable outcomes, and merchant policies.

## Not a Notification System
Notifications are possible execution mechanisms, not the product.

## Unique Layer
Failure → context → diagnosis → candidate actions → recovery prediction → expected value → guardrail → execution → measurement → learning/re-planning.
