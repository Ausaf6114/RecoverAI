# Tech Stack

## Backend
Python + FastAPI.

## Database
PostgreSQL.

## Analytics
SQL + Pandas.

## ML
Start with Logistic Regression; evaluate XGBoost only if justified by validation.

## LLM
Tool-calling LLM with structured outputs.

## Agent Orchestration
Lightweight custom state machine initially. Use LangGraph only if it materially improves state/orchestration without unnecessary complexity.

## Razorpay
Official MCP/API integration, subject to actual tool availability.

## Frontend
React/Next.js.

## Events
Webhooks for outcome confirmation.

## Testing
Pytest/API integration tests plus deterministic simulator tests.

## Deployment
Keep deployment simple; exact hosting platform is **TO VALIDATE**.

## Principle
Do not introduce unnecessary technologies.
